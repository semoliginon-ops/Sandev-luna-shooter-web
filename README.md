# SANDEV Luna Shooter 🚀

Mainkan SANDEV Luna Shooter langsung dari browser — tanpa memasang APK.

## Cara bermain
1. Buka link GitHub Pages yang dipasang pada bagian **About** repo ini setelah deployment aktif.
2. Buat nama pilot, pilih hero, lalu tekan **SIMPAN PROFIL**.
3. Tekan **PLAY GAME** dan mulai petualangan.
4. Di battle, gunakan kontrol sentuh di layar. Di desktop, gunakan WASD atau tombol panah.

## Fitur
- HTML5 Canvas shooter dengan kontrol sentuh dan keyboard
- Profil pilot dan progres lokal di browser
- Hero, stage, boss, equipment, dan upgrade
- Companion Luna & Lola serta perintah battle
- Musik dan efek suara

## Penyimpanan
Progres tersimpan di penyimpanan lokal browser/perangkat yang digunakan. Progres tidak otomatis tersinkron ke perangkat lain. Menghapus data situs/browser dapat menghapus save lokal.

## Hosting
Situs ini disiapkan untuk GitHub Pages melalui GitHub Actions workflow di `.github/workflows/pages.yml`.


Deployment automation: GitHub Actions is configured to enable Pages and publish the game on pushes to `main`.
